# 경량화 스터디 기록

[8주 커리큘럼](../경량화_8주_커리큘럼.md)에 맞춘 주차별 기록 템플릿이다. 각 주차 파일을 열어 작성하고 아래 진행 현황을 갱신한다.

## 사용 방법

1. 모임 전에는 날짜·역할·읽은 범위·사전 질문을 채운다.
2. 모임 중에는 학습 내용·토론·실험 조건·결과를 기록한다.
3. 모임 후에는 산출물 경로와 다음 할 일의 담당자·기한을 정리한다.
4. `—`는 미입력 표시다. 수행하지 않은 내용은 `미진행`, 측정하지 않은 값은 `미측정`으로 구분한다. 체크박스는 실제 완료 후 표시한다.
5. 여러 실험은 실험 ID로 구분한다. 같은 주차에 여러 번 모였다면 파일을 날짜별로 복사하거나 모임별 기록을 추가한다.

예정된 논문과 실험 설정은 미리 넣었으며 결과는 비워 두었다. 실제 진행 내용이 바뀌면 수정해서 사용한다. 실험 조건과 결과표는 프로젝트를 선택한 범위에 맞춰 채우면 된다.
